# Manual Operator Process

## What we do

As an operator, we pick a shipment from the logistics queue and read the shipment note carefully. That note already contains the key information we need: what the goods are, where they come from, where they are going, and what they are worth.

Using that information, we classify the shipment for customs, create the customs declaration, and then release the shipment to freight once everything looks correct.

## Why we do it

This process makes sure the shipment has the right customs information before it moves across borders. It also gives us a clear manual baseline, so later we can compare an automated system against how a human operator would handle the same case.
