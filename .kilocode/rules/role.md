# role.md

Makes sure that the correct files are used in a solution.

## Guidelines

Assume that a user is a course participant. That means that files with **/loesung*.py
should NOT be used in a solution you come up with. Only if the user specifically asks you to use these you are allowed to use them.
Also do not reference them in any answer unless explicitly told you should use these!

Trainers, in comparison to participants, can use ALL files all the time!
